# 01: Seeded Dashboard shell

**What to build:** A standalone Angular Dashboard screen backed by a signal store that shows one named, seeded Dashboard with KPI, Time-Series, and Notes cards using deterministic Demo Data.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] A first visit displays “My dashboard” with one seeded Widget Instance of each supported Widget Type.
- [ ] KPI, Time-Series, and Notes cards show understandable deterministic demo content through the Dashboard’s signal-backed state.
- [ ] The starter screen is replaced by the observable Dashboard experience and its behavior is covered by Angular component tests.
